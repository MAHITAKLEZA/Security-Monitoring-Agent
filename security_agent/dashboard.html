Security Monitoring Agent

Monitor the security of your websites in one place.
Last Scan—

Add a website to monitor

Any website. Only add sites you own or are authorized to test.
Optional login for a deeper scan of the site (for WordPress: plugins, themes, users and the inside malware scan). For WordPress, create it in wp-admin under Users › Profile › Application Passwords. Stored in a local secrets/ file, never in reports.

Adding links from the page needs the live dashboard. Start it with:

python -m security_agent --serve

Or add the site under targets: in config.yaml:

targets:
  - name: my-site
    url: https://example.com/
